# 2026 Lesson Planner Calendar

## Overview

This repository contains my digital lesson planner for 6th Grade English Language Arts (ELA). It is designed to help organize lessons, assignments, and instructional pacing throughout the school year.

## Purpose

Our school follows an **8-day rotating schedule**, with only six classes meeting each day. Keeping track of where each class is in the curriculum can be challenging, so this project provides a streamlined planning system that automatically converts lesson plans into an easy-to-read calendar format.

## How It Works

- Lesson plans are entered into a Google Sheets planner.
- A Google Apps Script synchronizes the spreadsheet with this GitHub repository.
- GitHub Pages automatically publishes the lesson plans as a calendar website, making it easy to review instructional pacing throughout the year.

## Features

- 📅 Calendar view of daily lessons
- 🔄 Automatic updates from Google Sheets
- 📚 Organized by instructional day and rotation
- ✏️ Easy lesson planning and pacing adjustments
- 💻 Accessible from any device with a web browser

## Intended Use

This project is for my personal classroom planning and instructional organization. It allows me to quickly see what each class is learning on any given day while keeping lesson plans synchronized across platforms.
